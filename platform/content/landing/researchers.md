## What you can do

- **Record times exactly.** Times are whole numbers or fractions, never rounded when you save or export. Show them as Gregorian dates, Julian years, millions of years, SI units such as `1.5 ks`, or a format you script yourself.
- **Cite every moment.** The **Sources** plugin keeps a moment's or duration's source links. **Dating context** says whether a date is a day marker or an estimate, and **Historical dates** keeps the date as the source gives it, such as a Julian date, beside the timeline's own.
- **Search and link.** Search a timeline's titles and notes, and link to any moment, duration or search.
- **Compare datasets.** Stack timelines on one axis, with a scale and offset for each, to line up ones that count time differently.
- **Export in open formats.** An `.ochx` file is JSON with everything in the timeline, including its display settings and plugins. The desktop app saves `.och` SQLite files, and the [HTTP API](/docs/api) reads and writes timelines with an API key.

## What you can count on

- **Nothing is rounded.** A third of a second stays exactly a third, however far you zoom.
- **Notes never move data.** Editing a date's precision or its original calendar never changes the moment's time.
- **Every save is kept.** Each save to the server is a revision, listed under **History**, that you can open and export.
- **Run it yourself.** Install a server for your group, or use the desktop app or the offline file without one.
