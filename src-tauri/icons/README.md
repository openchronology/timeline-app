The desktop app's icon in each format its packages need, drawn by [`scripts/icons.mjs`](../../scripts/icons.mjs) from [`logo/`](../../logo/README.md), as named in `tauri.conf.json` (Linux), `tauri.macos.conf.json` and `tauri.windows.conf.json`.

## Contents

| File                     | What it is for                                    |
| ------------------------ | ------------------------------------------------- |
| [`icon.icns`](icon.icns) | The icon for the macOS app and disk image.        |
| [`icon.ico`](icon.ico)   | The icon for Windows, in sizes from 16 pixels up. |
| [`icon.png`](icon.png)   | The 256-pixel icon for the Linux packages.        |
| [`icon.svg`](icon.svg)   | The icon as a vector drawing.                     |
