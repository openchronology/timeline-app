The Node server behind the platform: the HTTP API, the PostgreSQL store with its incremental indexes and saved history, accounts and sign-in, collaboration and moderation, and the log receivers and import tools that write to timelines through the API. In production Next.js serves the API through `next-handler.mjs`, which starts the services in `platform.mjs`; `http.mjs` holds the routes. The modules import the shared timeline code from `dist/core.mjs`, so build the project (`npm run build`) before running or testing them. `schema.sql` is applied by `migrate.mjs` on every upgrade. See [architecture](../docs/architecture.md), [authentication](../docs/authentication.md), [collaboration](../docs/collaboration.md) and [the API](../docs/api.md).
