# shorts

Copyright (c) 2026 Athan Clark. SPDX-License-Identifier: GPL-3.0-only

The scripts and storyboards of OpenChronology's vertical shorts for TikTok, YouTube Shorts and Instagram Reels: 9:16, under 45 seconds, captions burned in, each taking one fact or motion from an explainer (`publicity/1-…` to `11-…`) to the feed where its audience is. Start with [the series plan](0-shorts-audiences-and-series.md). Each is rendered from [`publicity/video/`](../video/README.md) (folders `s01-…` to `s08-…`), which reads its scenes, on-screen text and narration straight from these files.
