# OpenChronology — Short 7: A Whole App in One HTML File. Script and Storyboard

**Runtime:** ~0:27 · **Shape:** the how-to · **Look:** Paper · **Aspect:** 9:16
**For:** privacy-minded and open-source feeds. They've been burned by accounts, subscriptions and apps that phone home; the surprise is an artifact: an entire editor in one file that never touches the network.
**Purpose:** show the file, show what it doesn't need (a network, an account, an install), and the honest catch (nothing is kept until you export), with the way out: the same export opens in the desktop app and on the website.
**Points to:** Video 3, website, desktop or offline.

**Production notes:**

- About 70 words, plain and a little dry.
- Drawn, as Video 3 draws its editions: the file icon, a USB stick, a laptop with its network crossed out, the `.ochx` chip. The editor inside the laptop can be a still of the real app.
- The catch is said, not hidden: this audience trusts a product that tells them its limits.

---

## ACT 1 · THE FILE (0:00 – 0:13)

### Scene 1 · 0:00 – 0:05 · One file

**FRAME:** A single large file icon in the middle of the frame: `openchronology-offline.html` (as the release names it), and under it "the whole editor". Already whole at frame 0.

**MOTION:** The icon breathes once, a slow scale.

**OST:** "This entire app is one HTML file"

**VO:**
"This whole timeline editor is a single HTML file."

### Scene 2 · 0:05 – 0:13 · Never online

**FRAME:** The file drops onto a USB stick, then into a laptop whose Wi-Fi icon is crossed out; the editor opens on its screen. Three chips under the laptop, each crossed: "network", "account", "install".

**MOTION:** The file slides into the stick on "stick", into the laptop on "machine"; the chips strike through one by one on "no".

**OST:** "No network. No account."

**VO:**
"Carry it on a stick and open it on a machine that's never been online. It never uses the network. No account, nothing to install."

---

## ACT 2 · THE CATCH (0:13 – 0:23)

### Scene 3 · 0:13 – 0:23 · Export it

**FRAME:** The laptop's editor with **Export** lit, and an `.ochx` chip coming out of it; arrows from the chip to a desktop app window and to a browser window on the website.

**MOTION:** **Export** presses on "export"; the chip flies out; the two arrows draw on "desktop" and "website".

**OST:** "Nothing kept until you export"

**VO:**
"The catch: it keeps nothing when you close it, so export your work. That file opens in the desktop app and on the website too."
