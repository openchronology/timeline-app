# Investigations: from Timeline to Causal Factors

The source for the video of [`13-investigations-causal-factors.md`](../../13-investigations-causal-factors.md), in the **terminal** look. Build, narrate, render and encode it as [the pipeline's README](../README.md) describes. Narration, trimmed audio, captured shots, frames and the MP4 are not in git.

## Contents

| File                                    | What it is for                                                                                               |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| [`anim.js`](anim.js)                    | The scenes: SCENES[n](lt, q) draws scene n at lt seconds into it; q("word") is when that word is said.       |
| [`video.json`](video.json)              | The video's settings: its script, its look, respellings for the scratch voice, and scenes held longer.       |
| [`shots.json`](shots.json)              | The shots of the real app this tour captures (capture.mjs): the sample, keyframed views and actions.         |
| [`shots.mjs`](shots.mjs)                | Writes shots.json from the camera path in anim.js and the narration's cues, so zooms follow a new recording. |
| [`shots.js`](shots.js)                  | Generated by capture.mjs: each captured shot's frame count, for the page.                                    |
| [`timeline.js`](timeline.js)            | Generated by build.py: scene start times, lengths and word cues.                                             |
| [`cuts.json`](cuts.json)                | Generated by prepare.py: where the speech starts and ends in each narration clip.                            |
| [`captions.srt`](captions.srt)          | Generated by captions.py: the captions, in the script's wording, timed from the narration.                   |
| [`transcripts/`](transcripts/README.md) | Generated by prepare.py: whisper.cpp's word timings for each trimmed clip.                                   |
