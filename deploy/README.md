Everything that installs the OpenChronology server: the Docker images that `compose.yml` builds ([Docker deployment](../docs/docker.md)), and one folder per server package (#116). [`scripts/server-package.mjs`](../scripts/server-package.mjs) builds the packages with Docker into `server-artifacts/`; the [server packages workflow](../.github/workflows/server-packages.yml) builds and tests each one. The Debian folder is the reference layout: the RPM package uses its services, configuration and commands, and the FreeBSD package adapts its configuration templates. FreeBSD, Homebrew and Windows build from the platform-independent archive in `platform/`. Each package folder keeps the README its package installs for administrators (README.Debian and the like). Every Dockerfile stage that installs packages first has apt or dnf retry a failed download three times and give up on a stalled mirror after 30 seconds (#367), so a slow mirror fails a build quickly instead of hanging it. The package builds' curl downloads (the Rust installer, pgmp, Node.js) likewise retry, and give up on an attempt that stalls below 1 kB/s for 30 seconds or takes over 3 minutes; [`test/ci-workflows.test.mjs`](../test/ci-workflows.test.mjs) checks each stage does. The .deb and .rpm builds take the Node.js tarball they bundle from `OCH_NODE_TARBALL` when it is set (#369): `server-package.mjs` passes its folder as the Dockerfiles' `node-tarball` build context, and the package stage copies it instead of downloading it from nodejs.org. Given or downloaded, the tarball must have the SHA-256 the Dockerfile pins (`NODE_SHA256`, beside `NODE_VERSION`); the Debian Dockerfile's pair is the one [`scripts/node-tarball.mjs`](../scripts/node-tarball.mjs) and CI read, and the RPM Dockerfile's must match it. CI downloads the tarball once per job with that script and caches it, as downloading it inside Docker stalled from GitHub's runners; local builds without `OCH_NODE_TARBALL` download it as before.

## Contents

| File                                           | What it is for                                                                                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| [`debian-server/`](debian-server/README.md)    | The .deb server package for Debian and Ubuntu, whose services, configuration and commands the RPM package reuses.                           |
| [`freebsd-server/`](freebsd-server/README.md)  | The FreeBSD server package, built on FreeBSD from the platform archive, with rc.d services.                                                 |
| [`homebrew/`](homebrew/README.md)              | The Homebrew formula and commands for the server on macOS, published to the openchronology/homebrew-tap repository.                         |
| [`platform/`](platform/README.md)              | The platform-independent server archive that the FreeBSD, Homebrew and Windows packages build from.                                         |
| [`rpm-server/`](rpm-server/README.md)          | The .rpm server package for Rocky Linux, RHEL and Fedora.                                                                                   |
| [`windows-server/`](windows-server/README.md)  | The Windows server installer, with its own PostgreSQL and Windows services.                                                                 |
| [`Dockerfile.app`](Dockerfile.app)             | The platform's Docker image (Compose's app service): the converter, the editor and the Next.js platform as a standalone Node.js server.     |
| [`Dockerfile.postgres`](Dockerfile.postgres)   | PostgreSQL 16 with the pgmp extension for exact rationals (Compose's database service).                                                     |
| [`plugins.example.json`](plugins.example.json) | An example plugin library: copy it, and set `PLUGIN_LIBRARY` to its path ([docs/plugins.md](../docs/plugins.md)) to publish its definition. |
