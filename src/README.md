The editor every edition shares, and its core. `app.ts` is the editor itself (with `index.html` and `styles.css`); the rest are its parts and the shared core: exact times and their presentation, the timeline index, durations, relationships, tags, plugins, search and the caches for timelines on a server or in a desktop file. `scripts/build.mjs` bundles it with esbuild into `dist/`: `app.js` and `app.css` for the browser editor, the desktop app and the website, `core.mjs` and a few other modules that the server, the platform and the tests import, and (through `scripts/offline.mjs`) the offline HTML file, which swaps `transport.ts` and `live-updates.ts` for `offline-transport.ts` and `offline-live.ts`. The platform (`platform/`) also imports some of these files directly. Times are exact rationals throughout (from `rational-ordered-map`), never floating point. See the [architecture](../docs/architecture.md) for how the parts fit.
