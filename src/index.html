Timeline time display

These settings belong to this timeline and are included in saved files and server copies. Event coordinates stay exact.

Numeric labels are rounded. SI prefixes work best with unit symbols such as s. A Julian year is exactly 365.25 days.

Proleptic Gregorian calendar with a fixed UTC offset. Input must include Z or ±HH:MM. Repeating fractional seconds print as {+n/d}.

Displayed value = (stored time − origin) / scale. For Gregorian display, the displayed unit is one second from 1970-01-01T00:00:00Z.

Each step is an exact interval in displayed units, smallest first. Adjacent steps define the subdivisions. For custom printers, use stored coordinate units. Beyond this list, graduations continue by powers of ten.

Define function print(time, api) and function parse(text, api). Optional Rational, TimeAPI and primitive type annotations are supported. Only const declarations, return, string concatenation, comparisons, conditional expressions and api calls are allowed. No globals, imports, property access, loops or other function calls.

Available API

rational(text), parseNumber(text), exact(q), add/sub/mul/div(q,q), neg(q), abs(q), compare(q,q), decimal(q,places), scientific(q,digits), timestamp(q,offsetMinutes), parseTimestamp(text), trim(text), stripSuffix(text,suffix), slice(text,start,end), replace(text,from,to), upper/lower(text), startsWith/endsWith(text,prefix). Custom code receives only the exact coordinate; unit scale and origin are handled by your code.

Preview uses the current window span and viewport width. Custom helpers: hasView(), viewLeft(), viewRight(), viewSpan(), viewWidth(), unitsPerPixel(), labelResolution(), purpose(). Existing printers and parsers can ignore this context.
